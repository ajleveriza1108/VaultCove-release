# VaultCove 0.9.5 Public Security Notes

0.9.5 expands local security engineering with Origin Trust Engine 2.0, Password Intelligence 2.0, stronger automated security regression/fuzz gates, and supply-chain documentation.

VaultCove remains offline-first for vault contents: encrypted credentials are stored/decrypted locally; licensing/device services are not cloud vault storage.

These notes intentionally omit private keys, license secrets, operational Script Properties and internal customer data.
